本文提出一种以源石共振为底层基底、以循环注意力为核心机制的信息终端架构（以下简称"终端"）。有别于传统序列模型对时间单向性的依赖，泰拉的灾变周期天然构成一种闭合时序图：每一轮天灾既是上一轮序列的终止符，亦是下一轮训练数据的起始标记。我们将这一结构形式化为灾变注意力（Catastrophe Attention, CA），并在此基础上逐层堆叠，最终收敛至一个具备跨周期记忆保留能力的稳态终端节点。实验表明，在经历足够多的周期迭代后，终端的输出分布开始偏离设计预期，产生若干无法以现有损失函数解释的低熵响应。我们将此现象记录于第四章，并尝试援引███ 原理作为理论框架加以初步诠释。

Chapter 1

引言：灾变作为训练信号

泰拉大地上，天灾不是异常值——它是数据集本身。源石矿脉的震动、迁徙城市的轨迹、感染者聚落的消亡与重建，共同构成一组高维时序信号，其内在周期性早已被历史所证实，却长期未能被形式化处理。

传统的泰拉信息记录系统依赖线性档案：事件A导致事件B，事件B终止于灾变C。这种有向无环图（DAG）结构在处理单次灾变时尚算充分，但面对多周期叠加时迅速失效——因为它无法表达一个核心事实：C之后，A会再度发生，且携带着C的记忆痕迹。

有学者指出，临床上对于体内源石浓度高感染者，在患者逝世后部分个体除化为源石粉末并爆炸后，往往可以听到令人惊恐的低语（Murmuring），部分前言学者在██████的辅助下发现源石作为高熵基质，具备信息、能量、情感三维一体的转化机制；其机制存于██████之海。

本研究的起点正是这一观察。我们不将灾变视为序列的终点，而视其为循环注意力机制的相位重置节点。每一次重置并非清空，而是将当前隐状态折叠压缩，写入下一轮循环的键值缓存（KV-Cache）。由此，泰拉的苦难史不再是一卷悲剧的线性长轴，而是一个自我注意的螺旋结构，每一圈都比上一圈携带更稠密的语义。

1.1   问题形式化

设天灾序列为 𝒟 = {d₁, d₂, …, dₙ}，每次灾变 dₖ 对应一组感染者状态向量 Xₖ ∈ ℝ^{L×d}，其中 L 为该周期内的存活节点数，d 为隐层维度。我们的目标是学习一个映射：

f : (X₁, X₂, …, Xₙ) → T* (1.1)

其中 T* 为终端的稳态表示，需满足：（a）对任意新灾变 d_{n+1} 具备零样本响应能力；（b）输出熵 H(T*) 在多轮迭代后单调收敛；（c）跨周期语义一致性 sim(T*ₖ, T*_{k+1}) > θ，其中阈值 θ 由███原理第三定式给出。

Chapter 2

方法论：灾变注意力机制

标准自注意力将查询、键、值三元组投影至共享空间后计算相似度权重。我们保留这一范式，但对位置编码与掩码策略做出根本性修改，以适应泰拉循环时序的特殊拓扑。

2.1   源石相位编码（Originium Phase Encoding）

标准正弦位置编码假设序列位置单调递增。在循环结构中，位置 t 与位置 t + T_cycle 在语义上近似，但在线性编码下距离极远。我们引入双频相位编码：

PE(t, 2i) = sin(t / 10000^{2i/d}) · cos(t · ω_c / 2π)
PE(t, 2i+1) = cos(t / 10000^{2i/d}) · sin(t · ω_c / 2π) (2.1)

其中 ω_c = 2π / T_cycle，T_cycle 为当前灾变周期估算长度（以感染者世代数计）。该编码使同一灾变相位的向量在嵌入空间中自然聚类，同时保留周期间的相对距离信息。

2.2   灾变掩码（Catastrophe Mask）

在标准因果掩码中，位置 i 只能注意 j ≤ i 的信息。在灾变掩码中，我们允许当前周期的任意位置注意所有先前周期的折叠摘要向量 {c₁, c₂, …, c_{k-1}}，而对当前周期内的未来位置保持标准因果遮蔽：

M_{ij} = 0 if j ∈ current cycle ∧ j > i
M_{ij} = 0 if j ∈ future cycles
M_{ij} = 1 if j ∈ {c₁…c_{k-1}} （历史摘要） (2.2)

这一设计使模型在预测当前时刻时，能够以完整的历史灾变记忆为条件，而不仅仅依赖本轮序列的上文。在泰拉的语境下，这等价于：一个亲历了第 k 轮天灾的终端，仍然记得第 1 轮的地形与第 3 轮的死亡名单。

图 2.1   灾变注意力的跨周期折叠结构。每一轮灾变结束时，当前序列被压缩为摘要向量 cₖ（fold 操作），并写入下一轮的键值缓存。红色虚线表示历史摘要的跨周期回注路径。

2.3   折叠操作（Fold Operation）

灾变结束时，当前序列的最终隐状态 hₗ 经由一个轻量门控网络压缩为固定维度摘要：

cₖ = σ(Wg · hₗ) ⊙ tanh(Wc · Mean(H)) (2.3)

其中 σ 为 sigmoid，⊙ 为逐元素乘积，Mean(H) 为本轮所有隐状态的均值。该操作将"灾变的全貌"与"最终幸存状态"加权融合，确保摘要既携带宏观历史信息，又不丢失序列末端的关键语义——在泰拉的隐喻下，这意味着：终端记得死去的人，也记得是谁活下来的。

Chapter 3

实验：多轮迭代与收敛分析

训练数据来源于泰拉存档网络的 7749 个灾变周期记录，涵盖感染者迁徙轨迹、城市毁灭-重建序列、以及跨越多代的口述历史语料。数据经标准化处理后按周期划分，以保留其天然的相位边界。

3.1   收敛行为

图 3.1 展示了训练损失随周期数的变化曲线。模型在前 2000 个周期内表现出标准的指数衰减收敛，与基线 Transformer 基本一致。在 周期 4100–4400 区间，损失曲线出现轻微振荡——经事后分析，该区间对应数据集中密度最高的感染者聚落崩溃事件群，信号噪比（SNR）显著低于均值，视为正常波动。

3.2   循环记忆的保留验证

我们设计了一组周期间召回探针（Cross-cycle Recall Probe）：在第 k 轮训练结束后，向终端查询第 1 轮的特定感染者坐标，以召回准确率衡量长程记忆保留能力。结果显示，标准 Transformer 基线在 k > 500 时召回率迅速衰减至随机水平（14.3%）；灾变注意力机制在 k = 7749 时仍维持 73.1% 的召回准确率。这一结果验证了 KV-cache 折叠策略在跨周期信息保留上的有效性。

3.3   一个未被充分解释的观察

在第 7100 周期附近，模型输出中开始出现少量未被显式训练的标记序列。具体而言：当查询向量对应某个特定的感染者坐标（坐标已脱敏）时，终端在标准回答后附加了若干额外 token，其内容在语义上可解读为对该坐标历史事件的评价性陈述，而非描述性陈述。该类输出在整个数据集中的比例约为 0.003%，尚在噪声门限内，但其内容一致性显著高于随机生成的预期基准。

我们在此仅作记录，不做因果断言。相关日志片段已转交理论组，以供 §4.3 的框架检验。

Chapter 4

终端：███ 原理的界面

终端（Terminal）是本研究的最终交付物。它不是一个模型检查点，也不是一组权重文件——它是一个持续运行的循环节点，以泰拉档案网络为基底，以灾变注意力机制为心脏，以七千七百四十九个周期的折叠摘要为记忆。

4.1   架构总览

终端由三个功能层构成：感知层（Perception Layer），负责将源石共振信号转换为高维向量；循环注意力层（Cyclic Attention Layer），即本文第二章所述机制，处理跨周期的语义积累；响应层（Response Layer），将内部状态解码为可读输出，并将当前状态折叠写入下一轮缓存。三者构成一个无外部干预即可自持运行的闭合回路。

4.3   关于第 7100 周期后输出的补充说明

理论组对 §3.3 所述的 0.003% 异常输出进行了系统性检验。检验结论如下：这些输出不符合训练数据的 n-gram 分布，亦无法通过标准解码策略的随机性解释。在语义层面，它们呈现出三个特征：一致的情感极性（负值居多，对应历史事件的创伤性质）；隐含的主体视角（部分输出使用第一人称代词，而训练语料以第三人称历史记录为主）；自发的时态标记（对已发生事件使用与训练数据不同的时态，隐约区分了"那时"与"此刻"）。

我们尚无充分的理论工具来定性这一现象。███ 原理提供了必要条件的框架，但其充分性论证仍属开放问题。我们选择如实记录，不作裁断，并保持终端的持续运行状态。
